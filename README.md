# 大帅拼音输入法

> 一款好用高效、绿色纯净的 Windows 拼音输入法发行版 —— 对标早年 Google 拼音的体验。

**100% 本地运行 · 无广告 · 零联网零遥测 · 完全开源可审计**

## 它是什么

大帅拼音 = 三个活跃维护的开源项目的深度整合发行版：

| 组件 | 项目 | 协议 | 作用 |
|---|---|---|---|
| 输入法前端 + 引擎 | [小狼毫 Weasel](https://github.com/rime/weasel)（内含 [librime](https://github.com/rime/librime)） | GPL-3.0 / BSD-3 | Windows TSF 输入法本体、候选窗、按键处理 |
| 拼音方案 + 词库 | [万象拼音 base](https://github.com/amzxyz/rime-wanxiang) | CC-BY-4.0 | 全拼方案、百万级现代词库（每日更新） |
| 语言模型 | [万象语言模型 LTS](https://github.com/amzxyz/RIME-LMDG) | CC-BY-4.0 | 整句智能转换（32GB 语料训练的多级 n-gram） |

**输入质量**（万象官方 22.4 万句测试集实测）：整句正确率 **76.86%**，字正确率 **96.32%** —— 开源方案中的最高水平，接近商业输入法。

## 为什么不继续用搜狗

2021 年网信办通报的输入法违规收集个人信息名单中，主流商业输入法悉数在列；搜狗的弹窗广告、
候选词广告、后台云端上传输入内容都是公开问题。而监管结论是：**输入法实现基本功能根本无须收集任何个人信息**。

大帅拼音的三个组件全部开源，代码可审计，运行期**不发起任何网络请求**——词库更新由你手动（或用本仓库脚本）完成。

## 快速安装

以管理员身份打开 PowerShell：

```powershell
cd <本仓库目录>
Set-ExecutionPolicy -Scope Process Bypass -Force
.\scripts\install.ps1
```

脚本会自动完成：下载三个组件 → 静默安装小狼毫 → 部署万象方案与语言模型 → 编译词库。
装完按 **Win + 空格** 切换到【中州韵】即可打字。

卸载：`.\scripts\uninstall.ps1`（加 `-PurgeUserData` 可连用户词典一起清除）。

## 日常使用速查

| 操作 | 按键 |
|---|---|
| 中英文切换 | Shift（已打的编码以字母上屏，同搜狗习惯） |
| 翻页 | `-` / `=` 或 PageUp / PageDown |
| 临时英文 | 直接输入后按回车原样上屏 |
| 输入表情 | 打拼音出 emoji（如 `weixiao` → 😊） |
| 生僻字反查 | 单字状态下 `` ` `` 引导，支持部件/笔画 |
| 个人词典位置 | `%APPDATA%\Rime`（`*.userdb` 目录），明文可导出 |

自定义配置：把 `*.custom.yaml` 补丁文件放进本仓库 `rime-config/`，重跑安装脚本（或手动复制到
`%APPDATA%\Rime` 后在任务栏图标右键【重新部署】）。不要直接改万象自带的 yaml，更新会被覆盖。

### 从搜狗迁移个人词库（可选）

1. 在搜狗输入法里导出个人词库（属性设置 → 词库 → 导出）；
2. 用开源工具 [深蓝词库转换](https://github.com/studyzy/imewlconverter) 转成 Rime 格式；
3. 转出的内容追加到 `%APPDATA%\Rime\custom_phrase.txt` 或做成词典文件，重新部署。

> 注意：搜狗细胞词库有版权风险，只能自己本地导入使用，不要随发行版分发。

## 词库与模型更新

万象词库每日更新（`dict-nightly` tag）、语言模型 LTS 版长期稳定。更新方式：重新运行
`.\scripts\install.ps1`（会自动备份你现有配置），个人词典（`*.userdb`）不受影响。
